Data & figure construction

These interactive figures were built from predicted integrin-ligand binding affinities and statistical analyses performed in R. Explore how each figure was constructed and access the data behind it.

14

Receptor-ligand binding affinities

Predicted affinities were expressed as -log10(KD) and arranged into a receptor-by-ligand heatmap for each species. Receptors and ligands were grouped using Euclidean distance and complete-linkage clustering. AU bootstrap support from the original pvclust analysis is shown on the ligand dendrograms.

Binding-affinity data AU bootstrap results
15

Ligand-binding profile correlations

Within each species, Spearman rank correlations were calculated between pairs of ligand-affinity profiles across the integrin models. The resulting correlation matrices were displayed as heatmaps and clustered using a distance of 1 - rho and complete linkage.

16

Cross-species ligand-affinity profiles

For each ligand, median predicted -log10(KD) values were calculated across the integrin models within each species. Species and ligand profiles were clustered using Euclidean distance and complete linkage, and the similarity of species-level ligand rankings was assessed with Spearman correlations.
